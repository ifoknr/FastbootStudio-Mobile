# Notes for Claude sessions on this repository

## Release notes: Arabic and English
Every release's notes are written in both languages: the Arabic bullets (Gulf dialect),
then a line `**English**`, then the same bullets in English.

## Commits and pull requests
They show IFOKNR only (`.claude/settings.json`): no Co-Authored-By or session lines in
commit messages or pull request descriptions. The GitHub tool appends a "Generated by"
line to new pull requests; remove it with an update right after creating one.

## Releases
The first public version was the beta v1.0.0-beta.1 (Oct 19, 2026); the first stable one is
v1.0.0 (Oct 28, 2026). Both are built and signed by
`.github/workflows/release.yml` with the release key in the repository secrets. A version with a
dash is a pre-release. IFOKNR tests on his phones first: make a new release or tag only when he
says so.

## Brand (fixed: change only when IFOKNR asks)
The full guide and the source files are in `ifoknr/tools`, folder `brand/` (BRAND.md). In short:
- IFOKNR's mark is `IF` in the Swamp Ninja lettering on a soft deep-violet tile, and the name is
  `IFOKNR` in the same lettering, lilac to violet to rose on dark (darker violets on light).
  On an About page: mark, name, "Developer" under it.
- App and tool names are drawn in the Prixma Bold Italic lettering, small.
- Each app and tool has a fixed icon (dark tile, glow, its own colours); app icons are never violet.
- Never commit a font file (personal-use licences): text is drawn as outlines.
- Numbers in English digits in every language.
